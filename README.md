# Pilotes & Estudios Profesionales

Necesito crear una página web de mi cliente que tiene una empresa de pilotes, necesito una página simple y formal, recuerda que son proyecto profesionales con arquitectos así que tiene que ser formal y profesional, tiene que llevar los colores morado y blanco porque son los dos característicos de la empresa, la empresa ofrece los servicios de pilotes, submuraciones y estudios de suelos, la página tiene que mostrar información de quiénes somos, qué hacemos, nuestros trabajos y un formulario de contacto, te dejo el logo adjunto para que lo uses
